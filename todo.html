How syncing works
All calendar integrations run via Claude Code's pre-authenticated MCP connections — no OAuth setup needed.

• Reads (events shown in Calendar view) are fetched from Google Calendar and Outlook by Claude Code and stored in data/*.json.

• Writes (creating a todo as a calendar event or Craft task) go into a queue file. To process: tell Claude Code "process the MCP queue" or ask it to "create these todos in Google Calendar".

• Craft tasks shown here sync natively to your iPhone via iCloud.

• To re-sync calendar data, start a new Claude Code session and say "sync my todo calendar data".
