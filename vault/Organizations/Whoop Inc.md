# Whoop Inc.

Health wearable company. I use Whoop 4.0 for continuous HRV, sleep staging, and strain tracking.

## Key metrics tracked

- HRV (heart rate variability) — daily morning reading
- Resting heart rate
- Sleep staging (REM, deep, light)
- Respiratory rate
- Recovery score (0-100)

## Data exports

- CSV export available from Whoop app (Health Data section)
- Exports: daily recovery, sleep, strain data
