# Knowledge Management System

Building my personal PKM system using Obsidian + Life Cockpit. Goal: capture, connect, and act on knowledge without friction.

## Current stack

- **Obsidian** — main note editor, vault lives in `~/vault`
- **Life Cockpit** — web app layer for tasks, planner, health, AI
- **Readwise** — highlights from books/articles sync to vault

## Principles

1. Capture everything, curate later
2. Notes are for thinking, not storage
3. Links > folders
4. Every important entity gets a file
