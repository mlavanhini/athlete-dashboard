# Weekly Review

Sunday evenings, 7-8pm. Full GTD-style weekly review. 60 minutes.

## Current streak: 9 weeks

## Agenda

1. Clear inboxes (email, fleeting notes, physical inbox)
2. Review last week (tasks completed, tasks missed, why)
3. Review projects (next actions current?)
4. Review calendar for next 2 weeks
5. Set 3-5 weekly goals
6. Plan key calendar blocks for next week
