# Productivity Systems

How I capture, process, organize, and execute on work and life.

## Current system

- **Capture**: Life Cockpit fleeting notes + phone voice memos
- **Process**: Daily journaling + weekly review
- **Organize**: Obsidian vault with this tag/link structure
- **Execute**: Tasks module with weekly goals + daily prioritization

## Weekly rhythm

- **Sunday 7pm**: Weekly review (60min)
  - Review last week: what got done, what didn't
  - Set 3-5 weekly goals
  - Plan key blocks in calendar
- **Daily 8am**: Morning planning (15min)
  - Review today's tasks and calendar
  - Set 3 MITs (most important tasks)
