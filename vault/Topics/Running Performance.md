# Running Performance

Notes on training, race strategy, performance metrics, and improvement.

## Current fitness markers (June 2026)

- Lactate threshold: ~165 bpm / 7:10/mi pace
- VO2max estimate (Coros): 58 mL/kg/min
- Easy pace: 9:00-9:30/mi
- Marathon pace (target): 7:50/mi

## Key learnings

- My performance degrades significantly if sleep <7 hrs
- HRV below 55ms = adjust to easy day, regardless of plan
- Heat >75°F adds ~20-30 sec/mile to comfortable effort
